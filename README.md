# Arquitetura-da-mente-inabal-vel-

Landing page de **A Arquitetura da Mente Inabalável**, desenvolvida em React e Vite para apresentar o guia prático de estoicismo aplicado à vida moderna.

## Desenvolvimento

```sh
npm install
npm run dev
```

## Produção

```sh
npm run build
npm run preview
```

## GitHub Pages

O site é publicado automaticamente em `https://lavion234-spec.github.io/Arquitetura-da-mente-inabal-vel-/` quando há um push para `main`, pelo workflow `.github/workflows/deploy.yml`.

Em **Settings → Pages**, selecione **GitHub Actions** como origem de build/deploy, caso ainda não esteja configurada.

## Dados comerciais a configurar

Antes de publicar, substitua os campos indicados na página: URL do checkout, forma de pagamento, entrega e acesso, política de reembolso, responsável pela venda, contato de suporte e links legais. A referência de R$ 75 deve corresponder a um preço real e documentável. Nenhum checkout está conectado ainda.
